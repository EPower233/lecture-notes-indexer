## 三、评委如何验证（三条路径，由快到全）

### 路径 A — 看在线展示站（最快，零环境）
1. 打开 <https://lecture-notes-indexer-ejzc6ua0tvs.qoder.zone>。
2. `index.html`：点任一预置查询 → 出**真实 seekdb 抓取**的混合检索结果（分数/距离/相关度、课程/讲次/页码徽章、关键词高亮）。
3. 点结果卡片 → `note.html` 笔记详情（切片目录、术语卡、跨笔记链接跳转）。
4. `about.html`：架构、**单 SQL 融合公式**、EXPLAIN 证据、交付物对照、UID。
> 展示站为**静态快照模式**：Qoder Sites 后端是 Supabase/Deno，跑不了 seekdb 的单 SQL 向量+ik 融合，故站点内置从本机 live seekdb 实测抓取的结果（`tools/capture_snapshot.py`），**非编造**。完整在线混合检索见路径 C。

### 路径 B — 看代码仓库 + 文档（无需运行）
1. 克隆 <https://github.com/EPower233/lecture-notes-indexer>。
2. 读 `README.md`（总览）、`docs/开发记录.md`（过程/决策/UID）、`docs/验证样例.md`（真实输出）。
3. 核心代码：`schema.sql`（建表 DDL）、`search.py`（单 SQL 混合融合）、`ingest.py`（入库管道）、`serve.py`（HTTP 服务）。

### 路径 C — 本机复现完整 seekdb 混合检索栈（最全，需 Docker + Python 3.10）
按 `README.md`「快速开始」或《验证样例》§0：
```bash
docker start seekdb                                             # 宿主端口 20881
# 从零建库建表 + 入库（已入库可跳过）
py -3.10 -c "import pymysql; ...schema.sql..."                 # 见 README 完整命令
py -3.10 ingest.py
py -3.10 -m uvicorn serve:app --host 127.0.0.1 --port 8000     # 浏览器开 /ui/
py -3.10 verify.py                                             # 一键打印全部验证输出
```
> 依赖：torch · sentence-transformers(BAAI/bge-small-zh-v1.5, 512 维 CPU) · fastapi · uvicorn · pymysql · Docker Desktop。数据源为本地 Obsidian 讲义库（**只读**，由环境变量 `VAULT_DIR` 指定）。

## 七、如需更新后重新提交

- **改了源码/文档** → `git add … && git commit && git push`（仓库已是干净历史，正常追加提交即可）。
- **改了本机 seekdb 数据、要刷新站点快照** → 本机栈起来后 `py -3.10 tools/capture_snapshot.py` 重抓 → 走 Qoder Sites 发布流程（`prepare_site` → `publish_site`）→ 若新建站点默认私有，需 `update_access_policy` 设 public 并 `confirmPublic`。
- **换 UID/账号信息** → 同步更新 `docs/开发记录.md` 文首与本文件 §一#3、§四。
